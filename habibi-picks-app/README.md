# Habibi Picks - صانع المحتوى العاطفي التونسي

تطبيق متكامل لتوليد نصوص إعلانية عاطفية باللهجة التونسية للمنتجات التجارية.

## 📁 هيكل المشروع

```
habibi-picks-app/
├── backend/                 # خادم Express.js
│   ├── server.js           # ملف الخادم الرئيسي
│   ├── .env               # متغيرات البيئة
│   └── package.json
├── frontend/              # تطبيق React + Vite
│   ├── src/
│   │   ├── App.jsx       # المكون الرئيسي
│   │   ├── main.jsx      # نقطة الدخول
│   │   └── index.css     # التنسيقات
│   ├── index.html
│   ├── vite.config.js
│   └── package.json
├── setup.sql             # ملف إعداد قاعدة البيانات
└── README.md            # هذا الملف
```

## 🚀 البدء السريع

### 1. إعداد قاعدة البيانات

```bash
# إنشاء قاعدة البيانات
createdb habibi_picks

# تشغيل ملف الإعداد
psql -d habibi_picks -f setup.sql
```

### 2. تشغيل الخادم (Backend)

```bash
cd backend

# تثبيت المكتبات
npm install

# تعديل ملف .env حسب الحاجة
# DATABASE_URL=postgresql://postgres:password@localhost:5432/habibi_picks

# تشغيل الخادم
npm run dev
```

الخادم سيعمل على: `http://localhost:3001`

### 3. تشغيل الواجهة (Frontend)

```bash
cd frontend

# تثبيت المكتبات
npm install

# تشغيل التطبيق
npm run dev
```

الواجهة ستعمل على: `http://localhost:3000`

## 🎯 الميزات

- ✨ **توليد تلقائي للنصوص**: يولد نصوصاً إعلانية باللهجة التونسية
- 🎭 **ربط بالمشاعر**: كل منتج مرتبط بمشاعر محددة (فخامة، أنوثة، ندرة...)
- 📝 **محرر مدمج**: إمكانية تعديل النصوص المُولدة قبل النشر
- 💾 **حفظ المسودات**: جميع النصوص تُحفظ في قاعدة البيانات
- 🔄 **سجل المسودات**: عرض كل المسودات السابقة مع حالاتها
- 🇹🇳 **لهجة تونسية أصيلة**: بنك كلمات مفتاحية باللهجة التونسية

## 🗄️ قاعدة البيانات

### الجداول الرئيسية:

1. **emotional_keywords**: بنك الكلمات المفتاحية العاطفية
2. **products**: جدول المنتجات
3. **product_emotions**: ربط المنتجات بالمشاعر
4. **content_drafts**: مسودات المحتوى المُولد

### API Endpoints:

| الطريقة | المسار | الوصف |
|---------|--------|-------|
| POST | `/api/generate-caption` | توليد نص جديد لمنتج |
| GET | `/api/drafts` | جلب كل المسودات |
| PATCH | `/api/drafts/:id` | تحديث حالة مسودة |

## 🛠️ التقنيات المستخدمة

**Backend:**
- Node.js + Express.js
- PostgreSQL + pg
- CORS, dotenv

**Frontend:**
- React 19
- Vite
- Axios
- Tailwind CSS (via CDN)

## 🔧 التخصيص

### إضافة كلمات مفتاحية جديدة:

```sql

```

عدّل على دالة التوليد في `backend/server.js` في قسم "صياغة النص".
